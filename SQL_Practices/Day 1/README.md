# Day 1 – Introduction to SQL

## Introduction

Day 1 focused on the basics of SQL and how to create and work with a simple database. The lesson covered database creation, table creation, inserting records, retrieving data, filtering records, and sorting results.

## Lesson Objectives

- Create a SQL database.
- Create tables with different data types and constraints.
- Insert records into tables.
- Retrieve data using `SELECT`.
- Filter records using `WHERE`.
- Use operators such as `AND`, `OR`, `NOT`, `IN`, and `BETWEEN`.
- Use `LIKE` for text searching.
- Sort records using `ORDER BY`.
- Understand basic SQL table constraints.

## Activities Completed

### 1. Database and Tables
- Created the `school_db` database.
- Created the `students` table.
- Created the `teacher` table.
- Used constraints such as `PRIMARY KEY`, `NOT NULL`, `UNIQUE`, `CHECK`, and `DEFAULT`.

### 2. Insert Data
- Added student records to the `students` table.
- Added a teacher record to the `teacher` table.

### 3. Retrieve Data
- Used `SELECT *` to view table records.
- Selected specific columns such as student names and scores.
- Used `DISTINCT` to display unique values.

### 4. Filter Data
Practiced filtering records using:
- `WHERE`
- `AND`
- `OR`
- `NOT`
- `IN`
- `BETWEEN`
- `LIKE`

### 5. Sort Data
- Used `ORDER BY` to sort student scores in descending order.
