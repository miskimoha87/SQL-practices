# Day 2 – SQL Queries and Data Operations

## Introduction

Day 2 continued the SQL lessons using the `school_db` database. The lesson focused on aggregate functions, grouping data, modifying records, changing table structures, and working with dates.

## Lesson Objectives

- Use aggregate functions to analyze data.
- Count and group records.
- Filter grouped results using `HAVING`.
- Update existing records.
- Delete records.
- Add and modify table columns.
- Apply table constraints.
- Understand `TRUNCATE` and `DROP`.
- Work with current dates and date calculations.

## Activities Completed

### 1. Aggregate Functions
Practiced:
- `MIN()` to find the minimum score.
- `MAX()` to find the maximum score.
- `SUM()` to calculate the total score.
- `COUNT()` to count records.

### 2. Grouping Data
- Used `GROUP BY` to group students by age.
- Used `HAVING` to filter grouped results.

### 3. Modify Data
- Used `UPDATE` to change a student's score.
- Used `DELETE` to remove a record.

### 4. Alter Table Structure
Practiced:
- Adding a new column.
- Adding multiple columns.
- Adding a `CHECK` constraint.
- Changing a column data type.
- Dropping a column.

### 5. Table Operations
- Practiced `TRUNCATE TABLE`.
- Practiced `DROP TABLE`.

### 6. Date Functions
Practiced:
- `GETDATE()` to get the current date and time.
- `CAST()` to convert the current value to a date.
- `DATEADD()` to add days to a date.
- `DATEDIFF()` to calculate the difference between dates.

## Technologies Used

- Microsoft SQL Server
- SQL
- SQL Server Management Studio (SSMS)

## Process

1. Connected to the `school_db` database.

## Results

By the end of Day 2, I practiced using SQL for basic data analysis and data management. I learned how to summarize records, group information, modify data, change table structures, and perform date calculations.
